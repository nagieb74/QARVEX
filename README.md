# نظام إدارة المعارض (موقع حقيقي)

## التشغيل
```
node server.js          # يحتاج Node.js 18 أو أحدث، بدون تثبيت أي مكتبات
```
ثم افتح: http://localhost:3000  (غيّر المنفذ بـ PORT=8080 node server.js)

## أول استخدام
1. **أول حساب** تنشئه من «إنشاء حساب» يصبح تلقائياً حساب الإدارة (ID 1001).
2. أي شخص آخر ينشئ حساباً يأخذ رقم ID خاص به ويظهر له أنه بانتظار الصلاحيات.
3. من «المستخدمون والصلاحيات» ابحث بالـ ID وعلّم الصلاحيات المطلوبة ثم «حفظ»، ويسري التغيير فوراً.

## النشر على الإنترنت
- ارفع المجلد على أي استضافة Node (Render / Railway / VPS) وشغّل `node server.js`.
- فعّل HTTPS من الاستضافة، وإذا كان خلف Proxy شغّل بـ `TRUST_PROXY=1`.
- البيانات كلها في مجلد `data/` (أو المسار في DATA_DIR) — خذ منه نسخة احتياطية دورية، وعلى الاستضافة اجعله على قرص دائم.

## الأمان
كلمات المرور مشفّرة (scrypt)، الجلسات بكوكي HttpOnly، تذكرني = 30 يوماً، قفل مؤقت بعد 5 محاولات خاطئة، وكل صلاحية تُفحص في السيرفر.
